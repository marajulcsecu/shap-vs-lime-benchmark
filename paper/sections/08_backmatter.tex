\section*{Ethics and Reproducibility}
All \rev{five} datasets are public, de-identified benchmarks; no human subjects or clinical
deployments are involved, and no feature ranking should be read causally. Every number,
table, and figure is generated directly from code with pinned dependencies
(\file{requirements.lock.txt}), SHA-256 dataset checksums, and an artefact manifest
(\file{results/MANIFEST.json}; \rev{Python $3.12$, $12$-core CPU, single-threaded timing}).
