\section*{Ethics and Reproducibility}
This study uses three public, de-identified, redistributable benchmark datasets and
involves no human subjects and no clinical deployment. The diseases are benchmarks for a
methodological question in computer science; no model trained here is fit for diagnostic
use and no feature ranking should be read as a clinical or causal statement.

Every number, figure, and table in this paper is generated by code and none is transcribed
by hand. Dependencies are pinned to exact versions, source datasets are vendored with
SHA-256 checksums verified on every run, and a manifest records a digest for every
artefact alongside the git commit, the seed set, resolved library versions, and the
hardware. The analysis protocol was committed in its own commit before any commit
containing results, so the repository history is itself evidence that the hypotheses were
fixed in advance; all later changes appear in its amendment log with dates and reasons.
