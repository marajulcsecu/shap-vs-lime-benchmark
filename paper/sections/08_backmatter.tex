\section*{Ethics Statement}
This study uses three public, de-identified, redistributable benchmark datasets and
involves no human subjects, no personal data, and no clinical deployment. The diseases
are used as benchmarks for a methodological question in computer science. No model
trained here is fit for diagnostic use, and no feature ranking reported here should be
read as a clinical or causal statement.

\section*{Reproducibility Statement}
Every number, figure, and table in this paper is generated by code from
\texttt{results/}, and no value is transcribed by hand; the documents \texttt{\textbackslash input}
generated fragments. Dependencies are pinned to exact versions, source datasets are
vendored with SHA-256 checksums verified on every run, and
\texttt{results/MANIFEST.json} records a digest for every artefact alongside the git
commit, the full seed set, resolved library versions, and the hardware
(Table~\ref{tab:environment}). The analysis protocol was committed in its own commit
before any commit containing results, so the repository history is itself evidence that
the hypotheses were fixed in advance; all subsequent changes appear in its amendment
log with dates and reasons. \texttt{make all} reproduces the study from an empty
results directory.
