## A note on honesty here

If one or two people did most of the work, say so in proportion rather than flattening it — reviewers
and examiners read these statements, and an obviously uniform split across four authors on a
code-heavy project reads as boilerplate. Equally, every author should be able to answer questions about
their own listed area at the viva. Use `docs/PRESENTATION_GUIDE.md` to divide the anticipated questions
along the same lines as this table, so each person prepares the part they own.
