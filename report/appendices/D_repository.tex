\section{One command}
\begin{verbatim}
make setup     # create the virtualenv from requirements.lock.txt
make data      # download the three datasets, verify SHA-256
make test      # run the test suite
make smoke     # validate the whole pipeline in ~5 minutes (QUICK profile)
make all       # FULL run, then build paper, report, and slides
\end{verbatim}

\section{Why the protocol commit order matters}
\texttt{docs/PROTOCOL.md} was committed in its own commit, before any commit containing
a result. The repository history is therefore itself evidence that the hypotheses,
metrics, tests, and correction procedure were fixed in advance rather than adjusted
after seeing outcomes. Every subsequent change to the protocol appears in its \S10
amendment log with a date and a reason; five such amendments were made during
implementation, three of them triggered by tests catching genuine errors that would
otherwise have been invisible in the output.
